# Korean Learning Bot

Небольшой Telegram-бот для изучения корейских слов.

Бот позволяет создавать личный словарь и тренироваться в переводе слов. Проект сделан как учебный пример: здесь нет базы данных и сложной архитектуры — слова хранятся в обычном JSON-файле.

## Возможности

- добавление слов в личный словарь;
- тренировка перевода через `/learn`;
- отдельный словарь для каждого пользователя;
- хранение данных между запусками бота.

## Команды

| Команда | Что делает |
| --- | --- |
| `/start` | запускает бота |
| `/addword слово перевод` | добавляет слово в словарь |
| `/learn 5` | запускает тренировку из 5 слов |
| `/help` | показывает список команд |

Например:

```text
/addword 감사합니다 спасибо
```

После этого слово появится в словаре пользователя.

## Запуск

1. Установите Python 3.9+.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
4. Передайте токен через переменную окружения:

```bash
export BOT_TOKEN="ваш_токен"
```

Для Windows PowerShell:

```powershell
$env:BOT_TOKEN="ваш_токен"
```

5. Запустите:

```bash
python main.py
```

## Структура проекта

```text
.
├── main.py          # обработчики команд и логика бота
├── json_core.py     # чтение и запись пользовательских данных

├── requirements.txt # зависимости
```
